A multipurpose full site editing block theme for WooCommerce.

== Description ==

Suitemart is a multipurpose block theme built entirely on WordPress's own
platform features. There is no page builder, no jQuery, and no generated-CSS
engine: layout is edited in the Site Editor, design tokens live in theme.json,
and interactivity is built on the Interactivity API.

Commerce pages compose WooCommerce's own blocks. Cart, Checkout and My Account
are never replaced, so every payment gateway that supports the WooCommerce
block checkout keeps working.

== Requirements ==

* WordPress 6.7 or newer
* PHP 8.1 or newer
* WooCommerce 9.0 or newer (optional — required only for commerce features)

== Frequently Asked Questions ==

= Does Suitemart work with Elementor or WPBakery? =

No. Suitemart is a full site editing theme and supports the Site Editor only.

= Can I use Suitemart without WooCommerce? =

Yes. Commerce templates and blocks register only when WooCommerce is active.

= Where did the theme options go? =

Colours, typography, spacing and layout are edited in Appearance → Editor →
Styles. Behavioural settings live in Appearance → Suitemart.
